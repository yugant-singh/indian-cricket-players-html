# Indian Cricket Team - HTML Project

A simple HTML project showcasing profiles of Indian cricket team players using basic HTML tags.

## 📋 Description
This project features player profiles including MS Dhoni, Virat Kohli, Rohit Sharma, and other Indian cricket stars. Created to practice HTML fundamentals.

## 🛠️ Technologies Used
- HTML5

## 🎯 HTML Elements Practiced
- Headings (h1-h6)
- Paragraphs and text formatting
- Ordered and unordered lists
- Links and references

## 🏏 Players Featured
- MS Dhoni
- Virat Kohli
- Rohit Sharma
- Jasprit Bumrah
- Ravindra Jadeja
- And more...

*Created as part of HTML learning journey*

## 🚀 Enhanced Features (Newly Added)

### Semantic HTML Structure
- `<header>` - Website header with navigation
- `<nav>` - Menu for easy section access  
- `<main>` - Main content container
- `<section>` - Different content sections with IDs
- `<footer>` - Page footer

### Multimedia Elements
- `<img>` - Actual player images from Cricbuzz
- `<video>` - World Cup winning moments
- `<source>` - Video source elements

### Interactive Forms
- `<form>` - Fan poll for user interaction
- `<input type="radio">` - Voting options
- `<textarea>` - User comments section
- `<button>` - Submit actions

### Advanced Navigation
- Anchor links with `#section-id`
- Smooth scrolling between sections
- Organized menu structure
